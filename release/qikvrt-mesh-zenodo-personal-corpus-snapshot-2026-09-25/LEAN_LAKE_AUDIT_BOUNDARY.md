# Lean/Lake and Zenodo audit boundary

QIK-VRT combines standard DevOps evidence with a formally checked scientific-claim layer.

| Layer | Carrier | Evidence class |
|---|---|---|
| Source/DevOps | Git HEAD/TREE, CI, deterministic manifest | exact software subject |
| Archive/SaaS | Zenodo DOI/record/file hashes | persistent public artifact identity |
| Formal proof | Lean 4.19/Lake, axiom audit | theorem validity inside encoded models |
| Claim governance | claim graph, proof map, global inventory | explicit dependency/scope |
| Scientific boundary | OPEN/EMPIRICAL/INTERPRETIVE dispositions | what is not proved by the kernel |

Current bounded formalization status: 40/40 formal environments, 20/20 definitions, 20/20 theorem-like environments, 42 strong Lean bindings, 6 conditional bindings; 92 global claims with 3 OPEN.

## Spacetime emergence

The repository treats the emergence question through multiple connectable carriers: pre-spacetime ontology, relation-first causal models, QCE finite transition models, Planck-normalized/gap-law models, round-trip carriers and observer-relative information/causality models.

A Lean theorem is valid relative to its definitions and assumptions; it is not automatically a theorem that the physical universe instantiates the model. QCE therefore retains `PHYSICAL_CORRESPONDENCE = OPEN_CANDIDATE`.

This no-proof-inflation boundary is part of the audit contract.
