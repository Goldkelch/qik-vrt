# Zenodo record candidate: English current synthesis of observer-relative retrocausality

**Publication ID:** `qikvrt-observer-relative-retrocausality-en-current-synthesis-v1`

This directory prepares a new, independent Zenodo working-paper record for
the English current synthesis *Observer-Relative Retrocausality: Negative
Information Direction Along Monotonic Local Change Time*, version 2.1.

It is deliberately separate from the historical Zenodo record `21888130`
(`10.5281/zenodo.21888130`), which remains unchanged.  It is also separate
from the local arXiv staging path: no arXiv submission, identifier,
acceptance, or endorsement is claimed by this Zenodo candidate.

## Public upload set and controls

`FROZEN_UPLOAD_CANDIDATE.json` identifies the returned public research set.
`CLAIM_MATRIX_EN.json`, `SOURCE_EVIDENCE_BINDINGS_EN.json`,
`BOUNDARY_TEST_REPORT_EN.json`, `PREPUBLICATION_RETURN_RECEIPT_EN.json`, and
`MACHINE_PROOF_BUNDLE_EN.json` form the proof-bearing Zenodo-v2 upload set.
The metadata draft, authorization draft, production gate, exact owner
authorization, final manifest, finalizer, checksums, and workflow controls
remain repository-side and are never silently included as research uploads.

The candidate contains the 8-page English PDF, exact TeX source and source
archive, source/provenance and local-render receipts, the finite executable
witness and its canonical report, citation and license material, and the
claim/evidence/boundary/return proof artifacts.  The included finite witness
checks one declared operational model; it is not a Lean kernel receipt, an
independent empirical confirmation, or a claim of scientific consensus.

## Claim boundary

The work defines a negative information direction along a receiver's
monotonically increasing local-change-time chain and provenance-bound source
order.  It does not claim backward-running metric proper time, receipt before
emission, past overwrite, a causal loop, superluminal or past-directed
propagation, a controllable message into the causal past, independent
empirical confirmation, or scientific consensus.  The author's QIK-VRT
correspondence thesis remains explicitly attributed and distinct from the
finite model and its cited context.

## Status

The assembler only creates and verifies local, deterministic evidence.  It
does not contact Zenodo, inspect credentials, create a Git ref, create an
owner authorization, or publish a record.  Production remains blocked until
the exact returned candidate is author-authorized, its source and execution
commits are remotely bound, and the dedicated GitHub Actions publisher passes
its final preflight.
