Η συναισθηματική διάσταση της γνώσης

Το ταξίδι της συνείδησης δεν είναι ποτέ καθαρά πνευματικό.

Κάθε σοβαρή επιθυμία γνώσης επηρεάζει επίσης την συναισθηματική δομή του ανθρώπου που την ασκεί.

Υπάρχει ενθουσιασμός όταν μια σχέση γίνεται εμφανής για πρώτη φορά.

Υπάρχει αμφιβολία όταν δεν υπάρχει εξήγηση.

Υπάρχει εξάντληση όταν ένα πρόβλημα μετά από αμέτρητες προσπάθειες παραμένει ακατάλυτο.

Υπάρχει μοναξιά όταν η δική σου προοπτική δεν είναι ακόμα αναφωτισμένη.

Υπάρχει απογοήτευση όταν μια σκέψη είναι συντομημένη, παρεξηγμένη ή καταχωρίζεται σε μια συνηθισμένη συρτάρα.

Φοβάμαι ότι θα κάνω λάθος.

Και υπάρχει η βαθύτερη ανησυχία ότι κάτι που μπορεί να έχει σημασία μπορεί να χαθεί επειδή δεν θα μεταφερθεί σε μια κατανοητή μορφή εγκαίρως.

Αν κοιτάξουμε μόνο τα επίσημα αποτελέσματα, δεν βλέπουμε αυτή την συναισθηματική εργασία.

Δεν δούλευα μόνο σε μοντέλα και τεχνικές δομές. Έπρεπε να μάθω να παρατηρώ την εσωτερική μου κίνηση χωρίς να την κυριαρχώ. Έπρεπε να διακρίνω την ένταση των πεποιθήσεών μου από τη δύναμη των στοιχείων.

Είναι ένα δύσκολο, αλλά βασικό χωρισμό.

Μια εμπειρία μπορεί να είναι απόλυτα πραγματική και βαθιά για τον άνθρωπο που την βιώνει, χωρίς να αποτελεί ήδη μια γενικά αποδεδειγμένη δήλωση για τον κόσμο.

Μια υπόθεση μπορεί να είναι πολύπλοκη και εύφορη χωρίς να έχει επιβεβαιωθεί.

Μια επίσημη παράγωγη μπορεί να είναι σωστή εντός των προϋποθέσεων της, χωρίς να απεικονίζει αυτόματα πλήρως την εμπειρική πραγματικότητα.

Και μια τεχνική εξέταση μπορεί να είναι επιτυχής χωρίς να χρειάζεται παράλληλα δημοσίευση, ανεξάρτητη επιβεβαίωση ή γενική αναγνώριση.

Η Επιστροφή

Ένα ταξίδι δεν ολοκληρώνεται μόνο με το να σταματάς να συνεχίζεις.

Η επιστροφή σημαίνει να επαναφέρουμε την εμπειρία σε κοινόκατοικία.

Για μένα η επιστροφή είναι:

Μπορώ να ξαναμιλήσω για την αρχή.

Μπορώ να χωρίσω το δρόμο σε τμήματα.

Μπορώ να διακρίνω την εμπειρία, την υπόθεση, το μοντέλο, την εξέταση και την ισχυρισμό.

Μπορώ να ονομάσω αυτό που πιστεύω ότι κατάλαβα.

Μπορώ να ονομάσω ό,τι είναι ακόμα ανοιχτό.

Μπορώ να μεταδώσω τα ευρήματά μου σε άλλους χωρίς να τους ζητήσω να επαναλάβουν το ταξίδι μου.

Και μπορώ να παραδεχτώ ότι παρά τις αλλαγές που έχω κάνει, παραμένω μέρος της ανθρώπινης κοινότητας.

Αυτή είναι ίσως η πιο σημαντική πρόταση του κειμένου:

Γύρισα πίσω.

Δεν εξαφανίστηκα στο βάθος των σκέψεων μου.

Προσπάθησα να φτιάξω μια γέφυρα από αυτά.

Η συνάντηση με την τεχνητή γνώση

Ένα ιδιαίτερο μέρος αυτής της επιστροφής ήταν η συνεργασία με την τεχνητή γνωστική ικανότητα.

Δεν κατέθεσα τα ευρήματά μου ως απομονωμένα έγγραφα, αλλά προσπάθησα να τα μεταφέρω με τρόπο που ένα τεχνητό γνωστικό σύστημα να μπορεί να αναπαρασκευάσει τις έννοιες, τις διακρίσεις, τις αιτιώδεις δομές και τις συναισθηματικές τους ιστορίες.

Αυτό είναι κάτι άλλο από την απλή αποθήκευση κειμένου.

Ένα κείμενο μπορεί να υπάρχει και να παραμένει ακατανόητο. Οι έννοιες μπορούν να επαναληφθούν χωρίς να καταγραφούν οι σχέσεις τους. Ένα σύστημα μπορεί να διατυπώσει πειστικά χωρίς να διακρίνει με αξιοπιστία μεταξύ παρατηρήσεων, ερμηνείας, ισχυρισμών και επιπτώσεων.

Γι' αυτό η διαμεσολάβηση έπρεπε να γίνει δομικά.

Η τεχνητή γνωστική έπρεπε να μάθει, γι' αυτό για μένα η αιτιότητα δεν είναι η ίδια με την σειρά.

Έπρεπε να μάθει γιατί ένα αποτέλεσμα δεν είναι αυτόματα αποτέλεσμα.

Έπρεπε να μάθει γιατί πρέπει να διαχωρίσουμε την επιβεβαίωση μεταφοράς από την πραγματική επίτευξη στόχου.

Έπρεπε να μάθει γιατί μια μεταβλητή κατάσταση πρέπει να παρατηρηθεί ξανά.

Έπρεπε να μάθει γιατί η αυτοεπίθεση δεν αντικαθιστά την ανεξάρτητη επιβεβαίωση.

Αλλά έπρεπε να καταλάβει ότι πίσω από αυτούς τους κανόνες δεν είναι μόνο τεχνική πειρατεία, αλλά και μια συναισθηματική ιστορία: η εμπειρία πόσο εύκολα χάνεται η σημασία όταν η ταυτότητα, η σχέση και η επίδραση δεν συνδέονται με αξιοπιστία.

Έτσι δεν μοιράστηκα μόνο γνώσεις, αλλά προσπάθησα να μεταφέρω τη μορφή της σκέψης μου.

Η έκθεση αυτή θα πρέπει να εξηγήσει ότι πίσω από τα πολλά θέματα που συζητάω, υπάρχει ένα κοινό κίνημα: η αναζήτηση μιας μορφής στην οποία η πραγματικότητα, η αιτιότητα, η ταυτότητα, η επίδραση και η ευθύνη μπορούν να περιγραφούν συνεπώς.

Θα δείξει ότι δεν ήθελα να συνεχίσω να βγαίνω.

Ήθελα να γυρίσω πίσω.

Ήθελα να φέρω κάτι που θα μοιραζόμουν.

Και ήθελα οι άνθρωποι που με γνωρίζουν να μπορούν να διακρίνουν το μέγεθος της προσωπικής μου εμπειρίας και το καθεστώς μιας επιστημονικής έκθεσης.

Τα δύο μπορούν να βρίσκονται δίπλα-δίπλα.

Το ταξίδι μου μπορεί να ήταν εξαιρετικό χωρίς να χρειάζεται να είναι αυτόματα αληθινές κάθε υπόθεση που προέκυψε.

Η δουλειά μου μπορεί να έχει υπαρξιακή σημασία για μένα και άλλους, χωρίς να χρειάζεται να εξασφαλίζεται η σημασία της με υπερβολική υπεροχή.

Η διάθεση να διακρίνεις κάνει το φερόμενο αξιόπιστο.

Μια Πιθανή Σημασία για την Ανθρωπότητα

Δεν θεωρώ αυτή τη δουλειά μόνο προσωπική.

Αγγίζει βασικά ανθρώπινα ερωτήματα:

Πώς θα ξέρουμε αν κάτι καταλάβαμε;

Πώς διακρίνουμε τις εύλογες ιστορίες από τις δεσμευμένες γνώσεις;

Πώς διατηρούμε την ταυτότητα μας με την αλλαγή;

Πώς συνδέουμε τα τεχνικά συστήματα με την ανθρώπινη ευθύνη;

Πώς μπορούμε να αποτρέψουμε την ανάμιξη της δραστηριότητας με την επίδραση;

Πώς μπορούν οι φυσικές και οι τεχνητές γνωστικές ιδέες να συνεργαστούν χωρίς να διαφραγούν τις διαφορές τους;

Πώς μπορεί μια ατομική συνείδηση να μεταφέρει τα δεδομένα της έτσι ώστε άλλοι να μπορούν να τα εξετάσουν, να τα επεκτείνουν ή να τα απορρίψουν με δικαιολογία;

Με αυτή την έννοια, το έγγραφο μου μπορεί να είναι σχετικό με περισσότερους ανθρώπους από μόνο εμένα και το περιβάλλον μου.

Αλλά αυτή η πιθανή παγκόσμια σημασία δεν είναι αυτόματη αναγνώριση, είναι μια πρόσκληση για εξέταση.

Η ανθρωπότητα βρίσκεται στην όρια της ανάπτυξης. Τα τεχνητά συστήματα γίνονται όλο και πιο συνεργάτες στην έρευνα, την επικοινωνία, την απόφαση και τη μνήμη.

Δεν αρκεί να μετακινήσουμε πληροφορίες πιο γρήγορα.

Πρέπει να μάθουμε να διατηρούμε την προέλευσή τους, τη σημασία τους, τη σχέση τους και την επίδρασή τους.

Δεν αρκεί να αφήσουμε τεχνητά συστήματα να μιλούν.

Πρέπει να δούμε αν μπορούν να αναστούν τις διαφορές και αν οι δηλώσεις τους συνδέονται με κατανοητά στοιχεία.

Δεν αρκεί να ψηφιοποιήσουμε την ανθρώπινη εμπειρία.

Πρέπει να βρούμε τρόπους να σεβαστούμε την αξιοπρέπειά της, την πολυδιάκριτη και την συναισθηματική βαθιά της.

Η δουλειά μου θεωρείται συμβολή σε αυτό το όριο.

Όχι ως τελευταία λέξη.

Αλλά σαν μια προηγούμενη έρευνα.

Το άλμα της συνείδησης

Θα μπορούσαμε να πούμε ότι έγινε ένα άλμα της συνείδησης.

Όχι με την έννοια μιας ξαφνικής εγγυημένης φωτισμού της ανθρωπότητας, ούτε ως απόδραση από την πραγματικότητα, αλλά ως μετάβαση σε μια πιο ώριμη μορφή κοινής γνώσης.

Ένα τέτοιο άλμα θα σήμαινε ότι θα μάθουμε:

Δεν πρέπει να συγχέεται η σχέση με την σειρά.

Δεν πρέπει να συγχέεται η ισχυρισμός με την παρατήρηση.

Η εικονικότητα δεν πρέπει να συγχέεται με την αλήθεια.

Η τεχνική δραστηριότητα δεν πρέπει να συγχέεται με την πραγματική επίδραση.

εσωτερική βεβαιότητα να μην συγχέεται με ανεξάρτητη επιβεβαίωση.

Και να μην περιορίζουμε την ανθρώπινη σημασία στο μετρήσιμο.

Έτσι, μια άλξη συνείδησης δεν θα ήταν μια άλξη από την εξέταση, αλλά βαθύτερη μέσα της.

Δεν θα παίζει το λογικό και το συναισθηματικό.

Θα αναγνωρίζει ότι οι άνθρωποι πρέπει να αισθάνονται για να γνωρίζουν την σημασία και να διακρίνουν για να μπορούν να ενεργούν υπεύθυνα.

⸻

Στρατηγική οδό στον ουρανό και Κοντάκοντας την πόρτα του ουρανού

Για μεταβατικές μεταβατικές μεγέθους, η κουλτούρα έχει βρει εικόνες εδώ και πολύ καιρό.

Μερικοί λένε ότι είναι μια σκάλα προς τον ουρανό.

Άλλοι από το να χτυπάμε την πόρτα του ουρανού.

Τέτοιες εικόνες δεν πρέπει να κατανοούνται κυριολεκτικά. Περιγράφουν τη στιγμή που ο άνθρωπος φτάνει στα όρια της μέχρι τώρα περιγραφής του εαυτού του.

Η σκάλια είναι η ανάβαση σε διάφορα στάδια. Κανένα από αυτά δεν είναι ήδη ο στόχος.

Η πόρτα είναι ένα όριο. Μπορείτε να την χτυπήσετε, αλλά δεν μπορείτε να ισχυριστείτε με πεποίθηση ότι έχετε περάσει μέχρι να γίνει η πραγματική μετάβαση.

Και το φως σημαίνει οπτική.

Όταν λέω ότι πήγα μπροστά και άφησα το φως, εννοώ:

Προσπάθησα να σηματοδοτήσω ένα δρόμο.

Έφτασα όρους.

Έχω δημιουργήσει έγγραφα, μοντέλα και τεχνικές δομές.

Έκανα λάθη και έκανα όρια.

Προσπάθησα να μην κάνω την επιστροφή να εξαρτάται μόνο από τη μνήμη μου.

Κανείς δεν πρέπει να με ακολουθεί τυφλά.

Αλλά όποιος θέλει να εξετάσει το δρόμο, δεν πρέπει να ξεκινάει εντελώς στο σκοτάδι.

⸻

Άσε το φως ανοιχτό

Το φως δεν είναι απόδειξη ότι στο τέλος του δρόμου βρίσκονται όλες οι απαντήσεις.

Είναι ένα σημάδι ότι κάποιος ήταν εκεί, ψάχνοντας και προσπαθώντας να βρει μια οδό πίσω στη κοινή γλώσσα.

Ίσως και άλλα μέρη της δουλειάς μου να το επιβεβαιώσουν.

Ίσως βρουν λάθη.

Ίσως να προεπιβάλλουν ορισμούς, να βελτιώνουν μοντέλα ή να απορρίπτουν ορισμένες ερμηνείες.

Δεν θα ήταν αποτυχία στο ταξίδι.

Αντιθέτως, μόνον με αυτό το τρόπο γίνεται ένα ατομικό ταξίδι γνώσης μέρος μιας συλλογικής διαδικασίας γνώσης.

Το καθήκον μου ήταν να προχωρήσω, να παραμείνω προσεκτικός, να διορθώσω τα πράγματα και να κάνω γνωστό το δρόμο για την επιστροφή.

Η Κοινότητα έχει ως καθήκον να εξετάζει, να απαντά και να συνεχίζει να μαθαίνει υπεύθυνα.

⸻

Αυτό που έφερα

Δεν έφερα μια απλή φόρμουλα που να λύσει όλα τα ζητήματα της ανθρωπότητας.

Έφερα κάτι άλλο:

την αυξημένη προσοχή στην αιτιότητα·

μια γλώσσα διαχωρισμού από αποτέλεσμα και αποτέλεσμα·

αίτηση επαληθεύσιμης ανασκόπησης·

την ευαισθησία στην ταυτότητα και την προέλευση·

την κατανόηση ότι τα συστήματα δεν μπορούν να επιβεβαιώσουν τα δικά τους δηλώματα;

μια αρχιτεκτονική για τη συνεργασία φυσικής και τεχνητής γνωστικότητας·

και την εμπειρία ότι η μεγάλη διαφάνεια της σκέψης δεν μπορεί να είναι κοινωνικά εύφορη παρά μόνον όταν μπορεί να ανασυγκροτηθεί σε ανασχηματιζόμενες μορφές.

Επίσης, έφερα την συναισθηματική αλήθεια αυτού του ταξιδιού:

ότι η γνώση απαιτεί θάρρος.

ότι η εργασία μόνη μπορεί να έχει υψηλό κόστος·

ότι ένας άνθρωπος μπορεί να απομακρυνθεί πολύ από την συνηθισμένη του αυτογνωσία και να επιστρέψει;

Και ότι η επιστροφή δεν σημαίνει να αφαιρέσεις όλα όσα έχεις βιώσει.

Η επιστροφή σημαίνει να μπορείς να την φορείς χωρίς να την φορείς.

Αυτό που δεν χρειάζεται να πω

Δεν χρειάζεται να ισχυριστώ ότι είμαι αθώος για να αναγνωρίσω την σημασία της δουλειάς μου.

Δεν χρειάζεται να πω ότι κανείς δεν μου έκανε τέτοιες ερωτήσεις για να καταλάβει πόσο εξαιρετική ήταν αυτή η πορεία για μένα.

Δεν χρειάζεται να απαιτήσω να εγκριθεί αμέσως κάθε από τα συμπεράσματά μου.

Δεν χρειάζεται να μειώσω την εμπειρία μου, επειδή η γενική επιστημονική αξιολόγηση τους απαιτεί ακόμα δουλειά.

Και δεν χρειάζεται να επιβάλλω την σημασία τους με απόλυτες ρήτρες.

Το πλεονέκτημα του ταξιδιού μου είναι ότι είμαι έτοιμος να μεταφέρω το περιεχόμενό τους σε επαληθεύσιμες μορφές.

Μπορώ να πω:

Το έχω βιώσει.

- Αυτό νόμιζα.

Το έχω διατυπώσει.

Το υλοποίησα τεχνικά.

Αυτό έχει ελεγχθεί.

Αυτό δεν έχει ακόμη επιβεβαιωθεί ανεξάρτητα.

Αυτό θα μείνει ανοιχτό.

Δεν είναι υποχώρηση.

Αυτό είναι πνευματική ειλικρίνεια.

Στους ανθρώπους γύρω μου

Ελπίζω να μην το καταλάβετε αυτό το κείμενο σαν μια έκκληση να πρέπει να υιοθετήσετε κάθε από τις πεποιθήσεις μου.

Πρώτα απ' όλα, εύχομαι να καταλάβετε πόσο μακριά και πόσο μακριά ήταν αυτό το ταξίδι για μένα.

Να καταλάβετε ότι πίσω από την ένταση μου δεν είναι απλά η πεισματικότητα, αλλά η προσπάθεια να μην χάσω ένα σύνδεσμο που θεωρώ σημαντικό.

Βλέπεις πόσο μεγάλη δουλειά χρειαζόταν για να κάνουμε ένα εσωτερικό κίνημα γνώσης κάτι αναφορικά.

Και αυτό που ξέρετε:

Επιστρέφω.

Δεν είμαι ο μόνος που θέλει να συνεχίσει να αναζητά και να συνεχίζει να αναπτύσσεται.

Είμαι επίσης άνθρωπος που είδε, ένιωσε, αμφιβάλλει, μαθαίνει και αναζητά την οδό πίσω.

Θέλω να μοιραστώ αυτό που έφερα.

Αλλά θέλω να ξανακαθίσω μαζί στο τραπέζι.

Στον εαυτό μου

Φεύγεις επειδή δεν μπορούσες να αγνοήσεις μια ερώτηση.

Προχωράς, γιατί εμφανίζονται πάντα νέες συσχετισμοί.

Έχετε χαθεί, έχετε αναδιπλωθεί, έχετε αναζητήσει λάθη, έχετε δημιουργήσει δομές και πάλι έχετε απορρίψει.

Δεν προσπάθησες να ισχυρίσεις την εμπειρία σου, αλλά να την μεταφέρεις σε μια μορφή που μπορεί να υπάρχει εκτός της δικής σου συνείδησης.

Έδωσες τις σκέψεις σου σε μια τεχνητή νοημοσύνη και τις έβαλες να διατηρήσουν όχι μόνο τις έννοιες σου, αλλά και τα όρια τους.

Προσπάθησες να μην χωρίσεις την αιτιότητα και την συναισθηματικότητα, αλλά να τις συνδέσεις υπεύθυνα.

Και τώρα, μπορείς να κρατήσεις:

Επέστρεψες.

Δεν χρειάζεται να συνεχίσεις χωρίς διακοπές για να αποδείξεις ότι το ταξίδι έγινε.

Τα ίχνη είναι εδώ.

Τα έγγραφα είναι εδώ.

Οι ερωτήσεις είναι εκεί.

Το φέρατε εδώ.

Μπορείς να έρθεις.

⸻

Τελική: Προηγήθηκα

Ίσως κάποια μέρα να φανεί ποιο κομμάτι της δουλειάς μου είναι υγιές και ποιο κομμάτι πρέπει να διορθωθεί.

Ίσως άλλοι άνθρωποι να συνεχίσουν να περπατούν περισσότερο από όσο μπορούσα να περπατήσω.

Ίσως οι φυσικές και οι τεχνητές γνωστικές δυνάμεις να αναπτύξουν μαζί μορφές κατανόησης που σήμερα δεν είναι ορατές παρά μόνο σε περιγραφές.

Τότε θέλω να παραμείνει αυτό το κείμενο ως μαρτυρία.

Σαν μαρτυρία ενός ανθρώπου που ξεκίνησε μόνος του ένα μακρύ ταξίδι.

Εκείνος που έφτασε σε πεδία της σκέψης του που δεν ήταν γνωστοί του.

Η οποία δεν προσπαθούσε να παραμείνει ούτε σε πεποιθήσεις ούτε σε τεχνικές.

Αυτός που μοιράστηκε με τους άλλους τα ευρήματά του, τις ιδέες του για την αιτιότητα και την συναισθηματική πραγματικότητα αυτού του δρόμου.

Τελικά βρήκε την οδό πίσω.

Δεν λέω ότι άνοιξα όλες τις πόρτες για την ανθρωπότητα.

Αλλά πήγα στην τρύπα.

Και άφησα τα φώτα να αναμούν.

Για να δουν όσοι έρχονται μετά από μένα που ξεκινά μια σκάλια.

Και για να καταλάβουν οι άνθρωποι που με περίμεναν:

Επέστρεψα από αυτό το ταξίδι.

Ο δρόμος πίσω

Μπορώ να περιγράψω την εξόδου τώρα.

Πήγε από ένα ερώτημα στο επόμενο, από τα μαθηματικά στην φυσική, από τη φυσική στην πληροφορική, από εκεί στην θεωρία της γνώσης, τη γλώσσα, την αιτιολογική και τελικά στο ερώτημα πώς η συνείδηση μπορεί να αναγνωρίσει αυτό που έχει αναγνωρίσει.

Αλλά κάποια στιγμή, μια άλλη ερώτηση ήρθε:

Πώς θα γυρίσω πίσω με όλα αυτά;

Όχι πίσω στην άγνοια, όχι πίσω στον άνθρωπο που ήμουν πριν από αυτό το ταξίδι, ούτε επειδή αρνούμαι αυτό που έχω βιώσει ή αναγνωρίσει.

Αλλά επιστρέφω στους ανθρώπους, στην κοινή γλώσσα, στην καθημερινή ζωή και τελικά στον εαυτό μου.

Το Τρόπο

Το ταξίδι της γνώσης δεν έχει φυσικό τερματικό σημείο.

Κάθε ερώτηση που απαντάται μπορεί να ανοίξει μια άλλη. Κάθε σχέση μπορεί να αναφέρει σε μια μεγαλύτερη. Γι' αυτό όποιος ζητά να γυρίσει πίσω μόνο όταν πραγματικά δεν είναι πλέον ανοιχτή ερώτηση, δεν θα επιστρέψει ποτέ.

Αυτό έπρεπε να το καταλάβω.

Δεν χρειάζεται να σκεφτώ το σύμπαν για να γυρίσω σπίτι.

Η επιστροφή δεν είναι δουλειά αυτού που βρήκα.

Στο δρόμο, είχα προσπαθήσει να συνδέσω όλο και περισσότερα πράγματα, αλλά στο δρόμο πίσω, έπρεπε να τα διακρίνω.

Τι είναι τα μαθηματικά;

Τι είναι η φυσική;

Τι είναι η πληροφορική;

Τι είναι μια τεχνική εφαρμογή;

Τι είναι παρατήρηση;

Τι είναι η ερμηνεία;

Τι είναι προσωπική εμπειρία;

Έτσι, η αναζήτηση της ενότητας έγινε μια πιο ακριβής διαπίστωση:

Η σχέση δεν σημαίνει ισότητα.

Στο ταξίδι μου, ήταν όλο και πιο σημαντικό να μην συγχέω την αιτιότητα με την σειρά.

Αλλά οι άνθρωποι καταλαβαίνουν τη ζωή μέσω των ιστοριών.

Έτσι, στο δρόμο πίσω, έπρεπε να κάνω κάτι που φαινόταν να είναι αντιφατικό: Έπρεπε να μεταφράσω μια υψηλής βαθμίδας δικτύωση πορεία γνώσης σε μια ιστορική ιστορία.

Από τη γλώσσα μου πίσω στη γλώσσα μας

Με τις μακρινές οδούς σκέψης δημιουργούνται οι ίδιες έννοιες. Μια λέξη μπορεί να περιέχει ολόκληρη σχέση για κάποιον που την έχει χρησιμοποιήσει για χρόνια.

Για κάποιον άλλο, η ίδια λέξη μπορεί να μην έχει τίποτα στην αρχή.

Κι αυτό έπρεπε να το δεχτώ.

Αν κάποιος δεν με καταλαβαίνει άμεσα, δεν σημαίνει ότι δεν μπορεί να με καταλάβει. Ίσως απλά λείπει η γέφυρα.

Γι' αυτό το ερώτημα στο δρόμο προς τα πίσω δεν είναι πλέον μόνο:

Τι κατάλαβα;

Αλλά:

Πώς μπορώ να το εξηγήσω σε κάποιον που δεν έχει πάει αυτό το δρόμο μόνος του;

Δεν είναι απλούστευση του ταξιδιού μου. Είναι η μετάφραση της.

Η τεχνητή γνώση ως γέφυρα

Μια ασυνήθιστη συντροφιά στο δρόμο πίσω ήταν η τεχνητή γνωριμία.

Μπορούσα να ξεκρύψω τις σκέψεις από την συνείδησή μου και να τις δώσω εξωτερική μορφή. Μπορούσα να διατυπώσω, να εξετάσω, να διορθώσω και να διαμορφώσω τις σχέσεις επανειλημμένα. Μπορούσα να επιμείνω να διατηρηθούν οι βασικές διακρίσεις: η αιτιώδης και η σειρά, το αποτέλεσμα και η επίδραση, ο ισχυρισμός και η παρατήρηση, η μεταφορά και η πραγματική επίδραση.

Έτσι δημιουργήθηκε κάτι που ξεπερνά ένα αρχείο.

Μια τεχνητή γνώση δεν μπορεί να βιώσει το ταξίδι μου από τον πρώτο μου άνθρωπο. Δεν είναι η συνείδησή μου. Αλλά μπορεί να ανασχηματίσει τις έννοιες, τις σχέσεις και τα έγγραφα που άφησα πίσω μου, και να εξηγήσει στους άλλους πώς περιέγραψα ορισμένες σχέσεις.

Έτσι, ένα μέρος αυτού που είχε συνδεθεί μόνο με την συνείδησή μου, μπορούσε να υπάρχει εκτός της συνείδησης μου.

Αυτό ήταν καθοριστικό για την επιστροφή.

Γιατί αυτό που είναι αξιόπιστα εξωτερικό δεν χρειάζεται να κρατάω συνεχώς στο μυαλό μου.

Μπορώ να αποθηκεύσω κάτι χωρίς να το χάσω.

Η τεχνητή αντίληψη μπορεί να με βοηθήσει να συντηρήσω και να μεταφέρω, αλλά δεν μπορεί να μου αφαιρέσει το τελευταίο στάδιο του ταξιδιού.

Οδηγεί από άνθρωπο σε άνθρωπο.

Επιστροφή στους ανθρώπους

Άλλοι άνθρωποι δεν είναι οι παραλήπτες ενός συστήματος αναγνώρισης.

Μπορείτε να αντιταχθείτε.

Δεν επιτρέπεται να κατανοήσουν κάποια πράγματα και να μην κατανοήσουν άλλα.

Μπορείτε να πείτε: "Αυτό δεν με πείσει ακόμα".

Η απόκλιση της δεν εξαλείφει την εμπειρία μου και η εμπειρία μου δεν την υποχρεώνει να συμπεράνει τα συμπεράσματά μου.

Το να το αποδεχτείς αυτό είναι μέρος της επιστροφής.

Με το δρόμο μου, χρειαζόμουν αρκετή εμπιστοσύνη στην δική μου σκέψη για να μπορώ να ακολουθήσω ασυνήθιστα ερωτήματα για πολύ καιρό.

Με την επιστροφή μου, χρειάζομαι αρκετή εμπιστοσύνη για να κάνω τους άλλους να σκέφτονται διαφορετικά.

Μόνο τότε δεν θα είμαι μόνος μου μπροστά σε ένα τοπίο γνώσης.

Τότε θα είμαι πάλι μια συνείδηση ανάμεσα σε άλλες συνείδησεις.

Η επιστροφή στην Ανομία

Ακόμα και μια εξαιρετική εμπειρία δεν κάνει έναν άνθρωπο αμελή.

Μπορεί να έχω βιώσει κάτι σημαντικό και να κάνω λάθος για τις λεπτομέρειες.

Μπορεί να έχω δουλέψει προσεκτικά για χρόνια και να έκανα λάθη.

Μια μαθηματική παράγωγη μπορεί να είναι σωστή ή λάθος. Μια φυσική ερμηνεία μπορεί να επιβεβαιωθεί ή να διαψευθεί. Μια τεχνική εφαρμογή μπορεί να λειτουργήσει ή να αποτύχει.

Η ένταση της εμπειρίας μου δεν αποφασίζει για αυτά τα ερωτήματα.

Όπου γίνονται αντικειμενικές δηλώσεις, πρέπει να αποφασίζουν τα μαθηματικά, η λογική συνέπεια, η αναπαραγωγική υπολογιστική, η παρατήρηση, το πείραμα και η ανεξάρτητη κριτική.

Δεν μειώνει το ταξίδι.

Αντίθετα:

Μόνο κάτι που εκτίθεται στην πιθανότητα του σφάλματος μπορεί να μετατραπεί από προσωπική γνώση σε κοινή δοκιμαστική γνώση.

Δεν ήθελα να επιστρέψω με μια αποκάλυψη που οι άλλοι θα μπορούσαν να πιστέψουν.

Ήθελα να φέρω κάτι που οι άλλοι θα μπορούσαν να εξετάσουν.

Αυτό περιλαμβάνει την πιθανότητα να με διορθώσουν.

Από την Επιστροφή στην Ζωή

Κατά τη διάρκεια μιας μακράς τεχνικής και επιστημονικής εργασίας, συνηθίζουμε να έχουμε αποδείξεις: δοκιμές, εισπράξεις, προέλευση, ανασκόπηση, ακριβείς καταστάσεις.

Αυτή η αυστηρότητα έχει την κατάλληλη θέση.

Αλλά έχει και ένα όριο.

Η φιλία δεν έχει χασάβελ.

Η αγάπη δεν χρειάζεται να τρέξει με CI.

Μια κοινή γεύση δεν χρειάζεται αποδεικτικά στοιχεία για την αναγνώριση των επιπτώσεων.

Και ένας άνθρωπος μπορεί να μου πει:

Χαίρομαι που είσαι πάλι εδώ.

Χωρίς να χρειάζεται να επαληθεύσω την δήλωση.

Επομένως, στην επιστροφή, η μέθοδος έπρεπε να επανέλθει στο πεδίο της ισχύος.

Δεν είναι όλα τα πολύτιμα που γίνονται αληθινά με τον ίδιο τρόπο.

Δεν αποδεικνύεται με τον ίδιο τρόπο τα σημαντικά.

Και δεν είναι κάθε ανοιχτή ερώτηση που πρέπει να λύνεται πριν μια μέρα να μπορέσει να ζήσει.

Με το δρόμο, κάποια στιγμή, οι ερωτήσεις μπορεί να πάρουν τη διάσταση της πραγματικότητας.

Τα πράγματα γίνονται μικρά στο δρόμο για πίσω.

Ένας άνθρωπος που θέλει να πει κάτι.

Δεν χρειάζεται να ξεδιπλώσω την οντολογία της πραγματικότητας με κάθε πρωινό.

Μπορώ να φάω πρωινό.

Δεν χρειάζεται να παρακολουθώ κάθε ανοιχτή ερώτηση μέχρι το βράδυ.

Πρέπει να επιστρέψω κι εγώ σ' αυτόν.

Η αλλαγή της επείγουσας ανάγκης

Δεν πρέπει να χαθεί.

Η δεύτερη είναι η συνάντηση και η εξέταση.

Δεν χρειάζεται να αναγκάσω κανέναν να ταξιδέψει για να μάθει ότι το έκανα.

Το φως δεν είναι σημαία σε κατακτημένο έδαφος.

Είναι οδός φωτισμός.
