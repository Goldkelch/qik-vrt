AbNan × QIK-VRT

Privacy-safe Closed Roundtrip Witness V1. This is a technical reference model, not a live humanitarian case, regulatory approval, endorsement, or payment service.

Purpose

Demonstrate how one lawful, independently approved humanitarian-support case can be carried from a verified need to a freshly read-back effect while minimizing sensitive data and preserving accountable evidence.

Roundtrip

1. NEED
minimum case data
2. VERIFY
eligibility / identity
3. COMPLIANCE
independent gate
4. MATCH
roles assigned
5. ACCEPT
separate confirmations
6. LOCAL ACTION
no AbNan cross-border transfer
7. READBACK
effect evidence
8. CLOSE
complaint path retained

Fail-closed contract

REQUEST ≠ EXECUTION ≠ SUCCESS ≠ EFFECT

historical evidence may remain; current validity must be freshly earned

Any unresolved legal, sanctions, AML, privacy, security, identity, partner or evidence condition produces HOLD_UNVERIFIED, never an implicit approval.

Evidence envelope

Each transition binds a pseudonymous case identifier, state, timestamp, actor role, minimum required evidence digest, decision provenance and validity status. Sensitive beneficiary data is not part of this public witness.

Separation of responsibility

AbNan: humanitarian case coordination and accountable workflow. Independent professionals: legal, sanctions, AML, nonprofit, privacy and security approval. QIK-VRT: evidence-bound state transitions, readback, auditability, monitor projections and fail-closed semantics. Implementation partners: deliver components against explicit acceptance criteria.

Technical interfaces

The reference architecture can project privacy-filtered state through a read-only Monitorhook / Universal-Terminal interface. Clients may consume the same evidence graph without receiving unnecessary beneficiary data. Independent computational perspectives may flag counterevidence; disagreement is retained and cannot be voted away.

Definition of witness completion

A real pilot witness is complete only after independent approval for live operation, an authorized real case, lawful local action, separate confirmations, fresh effect readback, and documented closure on the same case subject.

This V1 page itself establishes only the executable/reference boundary. It deliberately makes no claim that those real-world conditions have already occurred.
