真相，还是垃圾信息？

如果人们再也无法可靠地追溯什么是真的、适用什么规则、谁负有责任、一个决定依据什么作出，那么逼近功能极限的就不只是数字传播体系，也包括法治本身。

Ingolf Lohmann，计算机科学家

缘起

2026年9月23日，联合国安全理事会讨论了先进人工智能带来的风险。OpenAI 和 Anthropic 的代表警告了严重的失控风险。

我认真对待这些警告。但根本问题比人工智能更古老：我们建设系统的速度，往往快于我们学会可靠控制其实际后果的速度。新的地方在于速度、规模，以及人工系统如今已经能够自行行动、通信并触发后续流程。

法治何时会出现“功能性破产”？

这里的“破产”不是法律上的状态，而是对制度功能失灵的一种警示性比喻。

法治依赖于这样一种可追溯性：适用什么法律、决定基于哪些事实、谁具有权限、决定如何被复核。如果来源、版本、证据和责任无法重建，问责就会越来越困难，法律在实践中就可能被单纯的权力所取代。

新的问题是：真相，还是垃圾信息？

一条重要信息在技术上完全可能与未经请求的群发信息没有区别。它可能是真实的，却消失在过滤器里；可能已经投递，却没有交给真正负责的人；也可能被阅读，却仍然在信息洪流中失去意义。

因此，数字系统必须重新能够回答：一个主张来自哪里？它指向什么对象？有哪些证据？证据的边界是什么？谁负责？实际执行了什么动作？声称的效果是否真的发生？

经济上的矛盾

领先的人工智能公司一方面警告失控风险，另一方面又处在异常激烈的技术和经济竞争中。

这不是对某个国家国民性格的判断，而是一种全球性的优化逻辑，在美国主导的人工智能市场中尤其明显：速度、资本、市场份额和技术领先会立刻得到奖励，而安全、可复现性和独立验证都需要时间。这是系统问题。

我的回答叫 QIK-VRT

我，Ingolf Lohmann，试图把人工认知变成另一种东西：不是一个只会令人信服地声称自己正确的系统，而是一个把主张、决定和实际效果绑定到可验证证据上的系统。

QIK-VRT 已经有公开的自动化自我审计。审计运行 29753095894 在其明确限定的范围内明确给出 PASS。审计报告、重新验证结果和可复现的验证状态均公开可查。

QIK-VRT 现在还包含一个与供应商无关的审计器，用于审计其他人工智能系统的证据绑定执行轨迹。一旦存在可审计轨迹，它会自动给出 PASS 或 BLOCK。这既不是对其他供应商的特权访问，也不是法律认证，而是一种可复现的技术审计格式。

为什么欧洲已经拥有正确的法律思路

根据具体用途，欧盟《人工智能法案》要求包括风险管理、文档、日志记录、技术稳健性以及有效的人类监督等措施。

核心思想很简单：控制必须真正有效。仅仅“有人在环”还不够，如果这个人无法理解边界、质疑输出或进行干预。QIK-VRT 在技术上处理同一个问题：一个动作不会因为被宣布或启动就算成功，真正重要的是能够证明的实际效果。

为什么自由新闻不能消失

如果公众再也无法可靠地区分可验证的信息、广告、自动化批量内容、操纵以及没有证据的断言，那么独立新闻反而会变得更加重要。

新闻自由是民主控制架构的一部分。在人工认知时代，新闻业还需要持久的来源、可见的版本、记录在案的更正，以及对新闻、评论、假设、证明和世界观解释的清晰区分。

为什么要创建 QIK-VRT Journal

已经发布的 URL 应当继续可访问。已经发布的版本应当继续可引用。更正不应抹去过去，而应当以可见方式补充过去。

每篇文章都可以用机器可读的形式携带其主张、来源和更正。代码仓库规则保护历史版本，防止静默改写。

一条新闻，六种语言，同一套证据

本文以内容等价的方式同时用德语、英语、法语、俄语、波斯语和中文发布；今后还可以按照同一合同加入更多语言。

差异化并不在于“多语言”本身。大型媒体几十年来一直进行多语言发布。QIK-VRT 的主张更窄也更可检验：每种语言版本都具有相同的文章 ID、版本号、段落 ID、主张 ID、来源集合和更正历史。CI 会阻止缺失或结构发生分叉的语言版本。

这远远超出计算机科学

数学可以证明形式命题。物理学必须用自然界检验模型。计算机科学可以让来源和效果具有可复现性。法律通过合法程序决定权利和义务。伦理学追问哪些行动是负责任的。新闻业使事件能够被公众核查。灵性可以解释意义与超越，但不能因此被包装成数学证明或物理证据。

正是对这些不同认识方式的清晰区分，才使它们能够有意义地连接起来。

自我审计公开可查

没有人必须相信这些主张。关键技术证据都是公开的。自我审计只证明其明确声明的范围；它不能替代法院、监管机构或法律要求的外部合规评估。

所以邀请很简单：不要相信。去核查。

真相，还是垃圾信息？

软件不会制造真相。但我们可以建设这样的系统：一个主张为何值得信任，始终可以被追溯和检查。

如果我们失去这种能力，失去的就不只是优秀的软件。我们会失去科学、法律、民主和自由公共空间能够相互争论所依赖的共同基础。
