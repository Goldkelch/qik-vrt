# Scientific and platform boundary

This bundle separates established distributed-systems literature, QIK-VRT primary-source implementation material, and platform publication events.

The article does not claim that logical clocks are physical clocks; that operational local process order is relativistic proper time; that later reception changes an earlier physical event; that message overtaking is physical retrocausality; or that a controllable signal can be sent into a sender's own causal past.

The encyclopedic core is supported by independent literature on happened-before relations, logical and vector clocks, causal communication, and causal consistency. The QIK-VRT mapping is a primary-source case study and research interpretation. It is not used to establish QIK-VRT's own Wikipedia notability or scientific consensus.

Wikipedia publication would require community-compatible placement, conflict-of-interest disclosure, reliable independent sources, and editorial acceptance. A repository candidate is not a Wikipedia article.

Zenodo publication would establish a persistent public record and byte identity, not peer review. QIK-VRT policy additionally requires the candidate-specific v2 machine-proof and prepublication-return chain before any upload.

arXiv submission would establish a preprint submission event if accepted by the platform; it would not establish peer review. This bundle does not preclaim an arXiv identifier.

An IETF Internet-Draft is an individual contribution. Submission or publication as an Internet-Draft is not an RFC, standard, working-group adoption, or IETF consensus.

No `PASS`, `FINAL_PASS`, `EFFECT_ACK_DONE`, physical-hardware execution, Wikipedia acceptance, DOI, arXiv identifier, or IETF consensus is claimed merely by this repository bundle.
