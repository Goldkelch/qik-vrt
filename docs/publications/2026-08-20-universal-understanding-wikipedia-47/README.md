# Universal Understanding / Universale Grammatik des Verstehens

This repository bundle is the canonical mesh entrypoint for one encyclopedic article and its 47-language translation set.

The article explains the relationship between distinguishability, information, relation, causal order, observer-local ordering, causal intermediate representation, reobservation and effect acknowledgement. It preserves the scientific boundary that operational local time is not automatically relativistic proper time and that causal reconstruction does not imply backward physical-time transport.
