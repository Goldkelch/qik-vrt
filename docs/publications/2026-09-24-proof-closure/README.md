# QIK-VRT Proof Closure — publication bundle

Publication ID: qikvrt-proof-closure-2026-09-24-v1

This bundle separates four layers:

1. human-readable German and English articles;
2. a machine-readable closure contract and claim matrix;
3. executable Python and Lean model checks in the repository;
4. an individual IETF Internet-Draft candidate limited to application-layer terminality semantics.

The central statement is:

> The final proof is not another proof of the same truth. It is the evidence that no proof obligation remains open for the same exactly bound subject.

Boundary: proof closure is relative to an explicit subject and declared obligations. It does not prove arbitrary premises, empirical truth, legal correctness, or universal finality.

External effects are tracked independently: repository persistence, Zenodo publication, IETF submission, email confirmation, public posting and public readback are separate states.
