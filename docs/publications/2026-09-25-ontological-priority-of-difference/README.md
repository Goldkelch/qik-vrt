## Zentraler Satz

> **Am Anfang muss ein Unterschied gewesen sein, denn sonst wäre alles nichts.**
>
> **Quod erat demonstrandum, Ingolf Lohmann.**

„Am Anfang“ bezeichnet ontologische Priorität, nicht einen ersten physikalischen
Zeitpunkt. „Nichts“ bezeichnet im formalisierten Satz die Abwesenheit bestimmbarer
Differenz.

Konsens.
