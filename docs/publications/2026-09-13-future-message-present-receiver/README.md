# Eine Nachricht aus der Zukunft braucht einen Empfänger in der Gegenwart

## Delayed Choice, QIK-VRT und das interventionelle Kriterium eines wirklichen Rückwärtskanals

Publication ID: `qikvrt-future-message-needs-present-receiver-v1`

Publication Index State: `repository_candidate_open_correspondence`

Autor: Ingolf Lohmann. Fassung 1.0 vom 13. September 2026.

Dieses Working Paper trennt experimentelle Quantenkorrelation, retrokausale beziehungsweise zeitsymmetrische Modellierung, skalierbare informatische Retrogradität und einen operationalen physischen Zukunft-zu-Vergangenheit-Kanal. Es formuliert die technische These, dass ein möglicher Rückwärtskanal erst durch einen bereits früher vorbereiteten Empfänger mit Zeitadressen, versiegelten Registern, Codebuch, Authentisierung, Replay-Schutz, Provenienz und Effect Acknowledgement zu einer Nachrichtentechnologie werden kann.

Der vorgeschlagene physikalische Grenztest ist interventionell: Ein früher Wert Y wird erzeugt und unveränderlich versiegelt; erst danach wird eine unabhängige spätere Wahl X getroffen. Ein positiver Rückwärtskanal verlangt eine vorregistrierte Abhängigkeit `P(Y | do(X=0)) != P(Y | do(X=1))` unter Ausschluss gewöhnlicher Vorwärtskanäle und nachträglicher Datenänderung. Ein solcher positiver physischer Kanal wird in dieser Veröffentlichung nicht als bereits empirisch bestätigt behauptet.
