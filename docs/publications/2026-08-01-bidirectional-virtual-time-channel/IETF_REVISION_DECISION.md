# IETF-Revisionsentscheidung

Der vorliegende wissenschaftliche Artikel ist kein Internet-Draft und wird
nicht als solches etikettiert.

Das öffentlich vorliegende individuelle Arbeitsdokument
draft-lohmann-qikvrt-effect-ack-02 beschreibt den Version-1-Effect-Ack-Record.
Es ist kein RFC und keine IETF-Billigung.

Die neue bidirektionale Sessionidee kann drei verschiedene Folgen haben:

1. Sie bleibt ein informatives Anwendungsprofil über dem bestehenden
   Effect-Ack-Record.
2. Sie ergänzt eine rückwärtskompatible Wire-Konvention.
3. Sie benötigt eine neue Wire-Version mit CDDL, Sicherheitsanalyse und
   Interoperabilitätsvektoren.

Ohne diese Entscheidung wäre eine Revision -03 wissenschaftlich und
protokolltechnisch verfrüht. Daher wird in diesem Kandidaten keine
Datatracker-Mutation beansprucht. Ein späterer -03-Kandidat muss separat
erzeugt, mit der kanonischen xml2rfc-Toolchain gerendert, vollständig
geprüft und vor einer authentisierten Einreichung bytegenau zurückgegeben
werden.
