Bindungsmodell

Der Runtime-Origin ist keine Wirkungsvollmacht. Jeder geschützte Effekt bleibt an QIK-VRT Effect_ack, exakte Subjektbindung und nachgelagerte Reobservation gebunden. Ein erreichbarer Browser, TCP-Port oder Transport-ACK ist daher weder PASS, FINAL_PASS noch EFFECT_ACK_DONE.
