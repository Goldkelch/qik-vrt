# Epistemische Dreierbeziehung

## Wirklichkeit - inneres Modell - Aussage

Die beiden Abbildungen verdichten eine erkenntnistheoretische Kette:

```text
WIRKLICHKEIT
-> selektive Wahrnehmung
-> internes Modell
-> sprachliche Aussage
```

Die Handskizze nennt die drei Pole „Alles“, „Einbildung“ und „Wahrheit“.
Für die wissenschaftliche Fassung werden diese Begriffe präzisiert:

- **Wirklichkeit** bezeichnet den Gegenstandsbereich, auf den sich eine Aussage bezieht.
- **Einbildung** bezeichnet hier wertneutral das im Geist gebildete interne Modell.
- **Aussage** bezeichnet das, was ausgesprochen, geschrieben oder anderweitig symbolisch dargestellt wird.
- **Wahrheit** ist nicht einfach der letzte Knoten dieser Kausalkette, sondern eine Bewertungsrelation zwischen Aussage, Bedeutung und Gegenstandsbereich.

Damit lautet die präzisierte Normalform:

```text
W = Gegenstandsbereich / Wirklichkeit
P = selektive Wahrnehmungsdaten
M = internes Modell
A = sprachliche Aussage

W -> P -> M -> A
```

Die Pfeile beschreiben mögliche Informations- und Bildungsprozesse. Sie garantieren noch nicht, dass jeder Übergang fehlerfrei ist.

## Was „Stimmt alles drei“ wissenschaftlich tragen kann

Eine starke epistemische Bewährung liegt vor, wenn

1. die Wahrnehmungsdaten den Gegenstandsbereich hinreichend zuverlässig abbilden,
2. das interne Modell die Daten und relevante Gegenbeispiele erklärt,
3. die sprachliche Aussage das interne Modell korrekt ausdrückt,
4. unabhängige Prüfungen keine tragenden Fehler finden.

Dann verbessert sich die Begründung der Aussage.

Die wörtliche Formel

> „Wenn die drei übereinstimmen, entsteht Wahrheit.“

ist jedoch zu stark. Wahrheit wird nicht durch bloße dreifache Übereinstimmung erzeugt. Mehrere Menschen können dasselbe falsche Modell teilen, ein Modell kann intern kohärent und dennoch gegenstandsfern sein, und eine korrekte innere Vorstellung kann falsch ausgesprochen werden.

Die wissenschaftlich belastbare Fassung lautet deshalb:

> **Wenn Wirklichkeitsbezug, internes Modell und Aussage unter Fehlerkontrollen übereinstimmen, verbessert sich die epistemische Bewährung. Eine automatische Wahrheitsgarantie folgt daraus nicht.**

„3 ist gut“ bleibt damit eine anschauliche Heuristik, kein mathematisches Wahrheitskriterium.

## Minimales Gegenmodell gegen die Wahrheitsgarantie

Nehmen wir an:

```text
Tatsächlicher Zustand: Die Tür ist offen.
Internes Modell:       Die Tür ist geschlossen.
Gesprochene Aussage:   „Die Tür ist geschlossen.“
```

Modell und Aussage stimmen vollständig überein. Auch mehrere Personen könnten dieses Modell teilen. Trotzdem ist die Aussage relativ zum tatsächlichen Zustand falsch.

Daraus folgt:

```text
KOHÄRENZ(MODELL, AUSSAGE)
!= KORRESPONDENZ(AUSSAGE, WIRKLICHKEIT)
```

Selbst eine erweiterte soziale Kohärenz genügt nicht:

```text
MEHRHEITSÜBEREINSTIMMUNG
!= WAHRHEITSGARANTIE
```

## Information über die Zeit

Der untere Teil des professionellen Posters stellt Vergangenheit, Gegenwart und Zukunft dar. Wissenschaftlich tragfähig ist die vorwärts gerichtete Informationskette:

```text
früheres Ereignis
-> physisches Artefakt oder gespeicherter Zustand
-> gegenwärtige Rezeption
-> gegenwärtige Wirkung
-> mögliche zukünftige Folge
```

Ein Buch, eine Datei, ein Bild, eine Aufnahme oder eine Spur kann Information aus einem früheren Ereignis in eine spätere Situation vermitteln. Das setzt Träger, Erhaltung, Lesbarkeit und Interpretation voraus.

Die Formulierung „Information transzendiert die Zeit“ ist deshalb nur in einer begrenzten Lesart belastbar:

> Information kann Zeitpunktgrenzen durch physische Träger und fortgesetzte Prozesse überbrücken.

Sie beweist nicht:

```text
INFORMATION_EXISTIERT_NACHWEISLICH_ZEITLOS
```

und sie erzeugt keinen rückwärts gerichteten physikalischen Wirkungspfeil:

```text
SPÄTERE_REZEPTION_FRÜHERER_ARTEFAKTE
!= PHYSIKALISCHE_RETROKAUSALITÄT
```

Die Geschichte wird durch spätere Rezeption nicht rückwirkend verändert.

## Anschluss an die prä-raumzeitliche Ontologie

Die Dreierbeziehung ergänzt die prä-raumzeitliche Ontologie auf epistemischer Ebene:

```text
ontologisch:
Unterschied -> Relation -> Information -> gerichtete Wirksamkeit

epistemisch:
Wirklichkeit -> Wahrnehmung -> Modell -> Aussage -> Prüfung
```

Die Ontologie beschreibt Bedingungen von Unterscheidbarkeit und Wirkung.
Die Epistemik beschreibt, wie ein erkennendes System daraus Modelle und Aussagen bildet.

Beide Ebenen dürfen nicht vermischt werden:

```text
ONTOLOGISCHE_PLAUSIBILITÄT
!= EMPIRISCHE_BESTÄTIGUNG

INFORMATION
!= WAHRHEIT

KOHÄRENZ
!= KORRESPONDENZ

AUSSAGE
!= GEGENSTAND
```
