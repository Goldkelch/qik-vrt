## QIK-VRT causal-order model

QIK-VRT is a software research project that explores explicit separation between causal order, temporal sequence, execution state, observation, acknowledgement, and evaluated improvement. A central design rule is that chronological or execution order alone does not establish causation.

The project uses a metagrammar that binds intent, object state, authority, evidence, causal prerequisites, effects, and proof obligations before an action is treated as admissible. Its experimental compiler path includes ANSI C89 components and a small Motorola 68000 target representation in which decision state, semantic witnesses, effect lifecycle, and the presence of an explicit causal predecessor are represented separately.

A repository-native test associated with pull request #796 evaluated the transition pattern `PAST -> CURRENT_BOUND_STATE -> ADMISSIBLE_FUTURE -> EFFECT -> REOBSERVED_STATE`. On exact source head `98d66de02e98d67af81655b028d15fbd60869bbc`, a dedicated GitHub Actions workflow completed two groups of five tests successfully. The test cases distinguished an observed improvement from a later-but-unchanged state and a later degraded state under an explicitly declared objective.

The project does not treat these software results as proof that physical time is identical to causal order, as experimental confirmation of quantum causality, or as evidence of machine consciousness. Those are treated as separate philosophical or scientific questions requiring independent empirical models and evidence.
