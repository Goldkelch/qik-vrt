Implementation update for draft-lohmann-qikvrt-effect-ack

A Firefox-based QIK-VRT Universal Terminal implementation has been integrated into the QIK-VRT repository stack with an exact-tree-preserving verification path.

The terminal accepts schema-valid information envelopes without using claimed temporal relation, source identity, or destination identity as receipt/display blockers. The envelope preserves these values as metadata. Supported temporal-relation labels include PAST, PRESENT, FUTURE, UNKNOWN, and UNBOUND. A FUTURE label is observer/context metadata; it does not by itself assert physical signalling into a causal past.

The implementation preserves the protocol distinctions relevant to Effect Acknowledgement: RECEIVED is not TRUSTED; DISPLAYED is not AUTHORIZED; STORED is not EXECUTED; FORWARDED is not EFFECT_ACKNOWLEDGED; TRANSPORT_ACK is not EFFECT_ACK; CAUSALITY is not SEQUENCE.
