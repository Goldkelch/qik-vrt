# TEMDD dogfood programs

`examples/temdd/qikvrt_convergence_v0_1.temdd` is the first production-shaped TEMDD program. It targets the complete QIK-VRT DoD and therefore cannot be admitted if that canonical conjunction is weakened. It also carries explicit context/perspective and a first-class Authority/Mirror relation with separate source and observation order.

`examples/temdd/temdd_self_application_v0_1.temdd` is the bounded `TEMDD(TEMDD)` self-description bootstrap: TEMDD parses and validates a TEMDD program whose subject is the TEMDD language itself. This is a semantic self-application witness, **not** a claim that the compiler is fully implemented in TEMDD.

Execution of repository effects remains delegated to admitted QIK-VRT actors; the bootstrap parser and browser IDE have no ambient mutation authority.
